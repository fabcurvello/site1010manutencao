# Site 1010 Manutenção

> Repositório didático: site institucional fictício criado em sala de aula para praticar HTML e CSS.

## Acesse online

Site publicado no GitHub Pages: **[https://fabcurvello.github.io/site1010manutencao/](https://fabcurvello.github.io/site1010manutencao/)**

## Sobre o projeto

Site de uma empresa fictícia de manutenção de computadores, a **1010 Manutenção**. Foi usado em oficina prática: o professor constrói a versão de referência e os alunos recebem um modelo para completar.

## Contexto acadêmico

Exercício aplicado em sala de aula, usado como prática guiada com os alunos.

## Estrutura do repositório

- `index.html`: página inicial com os serviços e chamada para agendar visita de orçamento.
- `estrutura.html`: página sobre o laboratório e a equipe, com vídeo do YouTube incorporado.
- `local.html`: página de localização com mapa incorporado (Google Maps).
- `css/estilo.css`: folha de estilos do site.
- `oficina-professor/`: versão da oficina feita pelo professor.
- `oficina-aluno/`: modelo de partida para os alunos, com marcações como `[AQUI ENTRA O TÍTULO]` para serem substituídas.

## Conceitos trabalhados em aula

- Estrutura básica de um documento HTML
- Navegação entre páginas com links
- Imagens, vídeos e mapas incorporados com `iframe`
- Estilização com CSS externo

## Tecnologias

- **HTML5**
- **CSS3**

## Como executar

Clone o repositório e abra o arquivo `index.html` no navegador. Não é preciso instalar nada.

```bash
git clone https://github.com/fabcurvello/site1010manutencao.git
```
